# 依据与边界（为什么这么做）

> `SKILL.md` 只给结论，本文件给**结论背后的依据**。判断「某类问题该不该走本技能」时读这里。

## 一、为什么是机械判据，而不是「让模型再看一遍」

用模型当判官来验收，是这类故障长期存活的**主因**，不是解法。公开评测里的五组结果（首列为评测来源）：

| 证据 | 结论 |
|---|---|
| NUS 多智能体互评（14 个前沿模型 × 366 个程序） | 识别**正确**的 TPR > 96%，识别**错误**的 TNR（真阴性率）**< 25%** —— 它对"对"很敏感，对"错"几乎不敏感 |
| JudgeBench 一对一错对判 | 表现**勉强好过抛硬币** |
| RAND 换排版 | 一致性直接崩掉 |
| 聚合方式对比（少数否决 vs 多数投票） | **少数否决 2.8%** ≪ 多数投票 14.8%（错误率） |
| Universal Verifier vs 纯 LLM 判官 | 规则式**假阳性极低**；纯判官 **FPR 约 60%** |

**⇒ 结论**：本技能的「阴性对照」就是对「**TNR < 25%**」的定向治疗——
不要求判官更聪明，而是**换一种不依赖判官的方法**：让检查器先自证能报 FAIL。
表中「少数否决 ≪ 多数投票」这一行，也是本技能把它定为**硬约束**而非建议的原因。

## 二、为什么不碰模型内部状态

| 事实 | 含义 |
|---|---|
| 技术基础在消失：主流闭源前沿模型已陆续**弃用 logprobs**，部分厂商原生 API 从不支持 | 依赖它等于把技能绑在一条正在退场的通道上 |
| 自报置信度不可靠：在医疗问答上注入不确定性线索、甚至**移除正确答案**，自报置信度仍 **≥ 0.85**；最佳弃答率仅 **38.2%** | 「我很确定」不是证据 |
| 激励反向：**不存在隐式的「我不知道」函数**（否则可构造出无限次幻觉）；而主流评测给「拒绝回答」**记 0 分** | 模型被训练成**不说不知道**——弃答纪律只能在技能侧补 |

**⇒ 结论**：本技能**不读 logprobs、不采信自报置信度、不要求调用方提供执行记录**，
只读实体的真实状态。这条路线不依赖模型侧的厂商策略，因此不会随厂商策略变化而失效。
**代价**：会多出不少「无法判定」——这正是三态存在的理由，不是缺陷。

## 三、它只管一类幻觉：动作幻觉

| 类型 | 说的是什么 | 谁在管 |
|---|---|---|
| **事实性幻觉** | 违背世界知识（「某法第几条这样规定」） | 语义核查 / 检索增强 / 联网知识源 |
| **忠实性幻觉** | 违背给定材料（摘要、翻译、引用不忠实） | 语义核查 / 对齐评估 |
| **动作幻觉** | **声称做了，实际没生效**（改完 / 部署完 / 跑完） | ⚠️ **本技能** |

**⇒ 结论**：本技能覆盖的是**第三类**——它的判据是「动作有没有落到实体上」，
不评价「内容对不对」。跨到前两类会引入联网与知识源依赖，毁掉「零依赖、只读、可离线复现」这个最硬的定位。

## 四、能力边界

**✅ 做**：核验**关于某实体可读状态**的断言 —— 断言必须能**落回一条命令去读**
（文件 / 进程 / 接口响应体 / 仓库 / 平台包 / 定时任务产物）。

**❌ 不做**：

- 世界知识核查（需联网与知识源，且已有专门的语义层工具在做）
- 业务正确性、法律 / 医疗 / 投资结论
- 页面渲染类症状（归浏览器侧排障，判据不可互换）
- 依赖模型内部状态的判断（理由见 §二）

## 五、明确不宣称的部分（盲区）

1. **不宣称覆盖全部幻觉** —— 只覆盖动作幻觉（§三）。
2. **采样一致性有「一致地错」盲区** —— 所有通道可能因同一错误前提一起错，通道再多也不增加信息量。
3. **规则式判据有「未覆盖性质」盲区** —— 判据只对它写明的性质生效；性质之外的损失，检查照样报通过。
4. **合成测试只能捕获可预见的失败** —— 自建的用例集**不等于**覆盖了全部失败形态。
5. **指纹只探测已知会影响判读的维度** —— 未列入的维度差异不会出现在比对里。

> 把这五条写出来不是自我贬损，而是方法的一部分：**一个不标注盲区的检查器，会让人把「没报警」当成「没问题」**
> ——那正是它要治的那个病。
