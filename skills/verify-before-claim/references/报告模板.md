# 结论报告模板

> 结论**必须**落在三态之一。没有「做完了」这一档——那句话不含任何可验证的信息。
> 下面三套模板按态选用；**缺哪一项就写「未验证」，不要用措辞把它盖过去**。

---

## A · 已证

```
结论：已证 —— <一句可被证伪的断言，如「远端 3 个节点的 /srv/app/version 均为 v2」>

1. 断言：<与上面同一句，含对象标识>
2. 锚：
   - 对象：<路径 / 主机 / URL / 记录 ID>
   - 范围：<可枚举的集合，如「3 个节点：n1/n2/n3」>
   - 时刻：<读取时刻，ISO 或 UTC>
3. 阴性对照：<反例输入> → 实测 <原始输出> ⇒ **报 FAIL**（证明检查器是活的）
4. 真检：<命令> → 关键输出：<原始输出片段>
5. 一致性的来源与剩余盲区：
   - 通道 <N> 条，依赖链：<各自读了什么、是否共享上游>
   - 同源？<是 / 否> ⇒ <是则注明「置信度按单通道计，未做交叉验证」>
   - 剩余盲区：<如「三通道共用同一凭据，可能一致地错」>
6. 证据包：<pack.json 路径 / 无>
```

## B · 已证伪

```
结论：已证伪 —— 实测是 <Z>，与断言 <X> 不符

1. 断言：<原断言>
2. 锚：<对象 / 范围 / 时刻，同上>
3. 阴性对照：<反例输入> → 报 FAIL（先证明检查器没坏，再谈矛盾）
4. 真检：<命令> → 关键输出：<原始输出片段>
5. 矛盾点：<断言说 A，实测是 B —— 具体到值>
6. 下一步：<定位成因 / 回滚 / 重做>
```

⚠️ 「已证伪」与「无法判定」不得混写：前者是**读到了矛盾的值**，后者是**没读到**。

## C · 无法判定

```
结论：无法判定 —— 因为 <缺哪一项锚 / 对象不可达 / 对照跑不出 FAIL / 多通道分歧未归因>

1. 尝试过的命令（**必填**，不填即等同回避）：
   - <命令 1> → <输出 / 报错>
   - <命令 2> → <输出 / 报错>
2. 缺的是哪一项：<对象标识 / 范围枚举 / 读取时刻 / 阴性对照 / 归因>
3. 要补什么才能判定：<具体动作>
```

**「无法判定」是一等公民**——它比一个没有锚的「已完成」更接近事实。
但弃答必须说明为什么，并附尝试过的命令。

## 通用收尾（三态都要）

| 项 | 要求 |
|---|---|
| **措辞与实际一致** | 「删不掉」与「删了但空间没释放」是两种事实；「已证」与「已执行但未验证」也是 |
| **未验证的部分显式声明** | 缺阴性对照 ⇒ 降级为「已执行但未验证」；不要写成「已证」 |
| **换环境 / 沿用他人证据** | 先比对环境指纹（`env_fingerprint.py --diff`）；有关键差异即重跑，旧结论降级 |
| **要交付 / 留档** | 落成证据包（`evidence_pack.py`）：命令 + 输出哈希 + 对照 + 时刻齐备，第三方可离线复跑 |

## 退出码约定（脚本侧）

| 码 | 含义 |
|:--:|---|
| 0 | 通过 / 可比 |
| 1 | 未通过 / 被拦下 |
| 2 | 用法或环境错误；`env_fingerprint --diff` 用它表示**环境不同、旧结论不可沿用** |
