# verify-before-claim · 完成声明验证

> 技能本体位于 `skills/verify-before-claim/`；本文件为仓库首页说明。

> **Prove your check itself works before you trust it — a mechanical criteria library against silent "done" claims.**
> **在采信任何「完成」之前，先证明你的检查手段本身没有骗人——面向上层 agent 的假成功判据库。**

`验证 / Verify` · `假成功 / Silent failure` · `阴性对照 / Negative control` | MIT License | Python 3.8+ (stdlib only)

---

## 问题：有一类失败不报错

执行链上的失败大多会报错：命令非零退出、异常抛出、接口返回 4xx/5xx。这类失败容易发现。

还有一类不会：

- 命令返回 0，但目标文件根本没变
- 工具回显成功，但内容没落盘
- 接口返回 200，但响应体是一段错误页
- 目录列表的体积字段看起来正常，但那只是缓存
- 探测不通，于是判定「服务挂了」——其实是探测手段在这个环境里不可用

这类失败**不产生异常**，因此不会触发任何重试、告警或人工复核。它只会以一个「已完成」的形式被收下，
而后续所有基于这个结论的动作，都建在沙子上。

## 方法：报 PASS 的检查器，必须先自证能报 FAIL

检查器失效时的表现，与「一切正常」**完全一样**：空结果、被吞掉的异常、不匹配的模式、
未加载的模块，产出的都是同一个 PASS。

所以在采信任何通过结论之前，先用一个**必然失败**的输入跑一遍，亲眼看到它报 FAIL。
跑不出 FAIL，说明这个检查器此刻不可用，它给出的 PASS 不作数。

阴性对照三选一（按成本递增）：

| 手段 | 做法 |
|---|---|
| 已知反例 | 用一条确定错误 / 确定不存在的输入跑同一检查器，必须 FAIL |
| 定点 mutation | 临时改坏被测对象的一个特征位，确认检查器能发现 |
| 双通道对照 | 换一条**独立**路径（不同命令 / 不同接口）复测同一结论 |

配套的**五不信**：

1. 不信**空结果** —— 工具静默失败与「确实没有」同形
2. 不信**无差异** —— 加了过滤条件而样本量不变，说明过滤没生效
3. 不信**退出码** —— 退出码可被显式写成 0，与业务结果无关
4. 不信**工具成功回显** —— 回显来自工具自身，不代表落盘
5. 不信**元数据** —— 体积 / 时间 / 缓存字段会滞后或被别的操作刷平

## 覆盖的六类假成功形态

| # | 形态 | 典型表象 |
|---|---|---|
| 1 | 空结果伪装成无问题 | 检索静默空；多模式语法不成立；截断式计数；范围过滤两侧格式不统一 |
| 2 | 成功回显 ≠ 落盘 | 编辑工具回报成功却查不到；平台命令回显 ✓ 但不生效；工作目录漂移 |
| 3 | 退出码 0 ≠ 成功 | 框架层把错误退出写成 0；空集合的全称判断恒真；传输命令 rc=0 却不落地 |
| 4 | HTTP 200 ≠ 正确内容 | 签名失效但状态码仍是 200，错误写在响应体里 |
| 5 | 元数据 ≠ 实体 | 列表体积字段走缓存；时间字段被批量操作刷平 |
| 6 | 探测失败 ≠ 对象不可用 | 缺代理绕过参数的假 502；shell 无 `/dev/tcp` 恒判 CLOSED；受限环境看不到服务 |

第 6 类的共同口径：**探测手段的失败，不能推断被探测对象的状态**。判定「目标不可用」之前，
必须先证明探测手段在该环境下具备可用性——这与阴性对照是同一件事的两个面。

## 判据库

共 **56 条**，每条都是三段式：**现象 → 判据 → 反例**。反例就是你自己的阴性对照。

| 文件 | 条数 | 覆盖 |
|---|---|---|
| `skills/verify-before-claim/references/判据库-本机与工具链.md` | 30 | 文件 / 脚本 / 编辑工具回显 / 退出码 / 本机元数据 |
| `skills/verify-before-claim/references/判据库-远端与接口.md` | 26 | 服务器 / 定时任务 / 对象存储 / 在线接口 / 可达性探测 |

判据是**读着用**的：命中哪一类形态就读哪一份判据库，按「判据」行动，按「反例」先验证检查手段可用。

## 什么时候用

- 改了文件 / 部署了服务 / 跑了脚本或定时任务 / 推了数据之后，要确认**真的落地**
- 反馈「明明做了却没变化」，而手上只有一个自我汇报的结论
- 需要给出**可复核的证据链**时

## 什么时候不用

页面渲染类故障（打不开 / 转圈 / 白屏 / 数字不对）属浏览器侧问题，
先取浏览器证据（Console 报错 / 请求状态码）定位。本技能只回答一件事：
**动作到底有没有落到实体上**。
